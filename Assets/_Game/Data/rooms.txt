// Комнаты игры «Пуля — дура». Правьте прямо здесь, в Unity изменения подхватятся при следующем Play.
// Строка «= Название | Подсказка» начинает комнату, дальше идёт карта. Пустые строки и строки с // пропускаются.
//
//   #  стена            c  ящик (ломается со 2 попаданий)     P  игрок
//   d  мишень (не стреляет)    r  новичок (стоит, стреляет медленно и мимо)    t  турель (стоит, стреляет на звук)
//   h  охотник (Стриж + Плазма, ездит на звук)      g  громила (Барсук + Дробовик)
//   s  снайпер (стоит, умеет стрелять через рикошет)  B  Бегемот с рельсой (босс)
//   q  щитоносец (щит спереди отражает пули — бей в бок или через рикошет)
//   y  жёлтый ящик (выпадает аптечка, щит, ваншот или метка)    x  красная бочка (взрыв + шрапнель)
//   n  ловушка-сирена (наехал — все враги слышат)    1..4  телепорты, ровно по два одной цифры (переносят танки и пули)
//
// Третье поле заголовка — эхо комнаты (AudioReverbPreset): Room, StoneCorridor, Cave, Hangar, Hallway, Arena, Auditorium...
//
// Новые типы врагов добавляются в GameConfig → Enemies, символ берётся из поля Symbol.
