# Пуля — дура

Танки в темноте. Стен не видно, пока пуля не отскочит от них: каждый отскок даёт вспышку эха, которая высвечивает стены и врагов. Игра для FunFlow Game Jam × ТПУ, вариант «Танчики».

## Запуск

Откройте папку в **Unity 6000.6.5f1** и нажмите **Play**: сцена `Assets/_Game/Scenes/Main.unity` откроется и запустится сама.

## Правила

1. Стен не видно — отскок пули высвечивает их на пару секунд.
2. Отскочившая пуля опасна и для тебя.
3. Враги почти слепы, но слышат выстрелы и двигатель. Уничтожь всех в комнате.

## Управление

| Действие | Клавиши |
|---|---|
| Ехать | WASD |
| Тихий ход | Shift |
| Целиться / огонь | Мышь / ЛКМ |
| Скилл корпуса | Пробел |
| Пауза | Esc |
| Переиграть комнату | R |
| Режим в гараже | Tab |
| Весь экран / окно | F11 |

## Что есть в игре

- **Гараж.** Три корпуса со своими скиллами и четыре пушки.

  | Корпус | Скилл |
  |---|---|
  | Стриж | рывок-таран |
  | Барсук | зеркало, отражающее пули |
  | Бегемот | временная стенка |

  Пушки: обычная, плазма, дробовик, рельса.
- **Режимы.** 8 сюжетных комнат или бесконечный режим с генерацией комнат и растущей сложностью.
- **Мир.** Бочки, которые взрываются и разбрасывают шрапнель. Порталы для танков и пуль. Скрытые сирены, решётки, зелёные ящики с бонусами.
- **Враги.** Восемь типов, включая щитоносца и босса Мамонта с рельсой.
- **Очки и таблица** лучших забегов на этом компьютере.

## Код

- Числа и настройки: `Assets/_Game/Configs/GameConfig.asset`.
- Сюжетные комнаты: `Assets/_Game/Data/rooms.txt` (текстовые карты, легенда в начале файла).

**Автотест:** соберите билд (меню «Пуля — дура → Собрать билд Windows») и запустите:

```
Builds/Win/PulyaDura.exe -autotest -shots C:\temp\shots
```

Билд играет сам и пишет результат в `qa.txt`.
