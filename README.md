# Пуля — дура

**Как запустить:** откройте папку проекта в **Unity 6000.6.5f1** и нажмите **Play**. Сцена `Assets/_Game/Scenes/Main.unity` откроется и запустится сама, какая бы сцена ни была открыта.

Игра для FunFlow Game Jam × ТПУ, вариант 2 «Танчики».

## Правила (30 секунд)

1. Стен не видно. Отскок пули — это вспышка эха: она подсвечивает стены и врагов.
2. Пуля отскакивает. После отскока она бьёт и тебя.
3. Враги тоже слепые, но слышат каждый выстрел. Уничтожь всех в комнате.

Глубже, но без новых систем:
- **Память эха.** Стена, которую ты хоть раз видел, оставляет еле заметный контур. Карта прорисовывается твоими выстрелами, а линия прицела показывает отскок от уже знакомых стен.
- **Каждый отскок ценнее.** С каждым отскоком пуля ярче, а её эхо шире. Убийство после 2+ отскоков даёт замедление и наезд камеры.
- **Тихий ход.** На полном ходу двигатель шумит, и враги едут на звук. С Shift танк едет медленно и бесшумно.

8 комнат, 3 жизни, забег занимает 3–5 минут. В гараже выбираются корпус (у каждого свой скилл) и пушка.

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Ехать | WASD / стрелки | Левый стик |
| Тихий ход (враги не слышат двигатель) | Shift | — |
| Целиться | Мышь | Правый стик |
| Огонь | ЛКМ | RT |
| Скилл корпуса | Пробел / ПКМ | LT / A |
| Заново | R | Select |
| Пауза | Esc | Start |
| В гараж (с экрана итогов) | G | — |
| Отладка: сразу в комнату 1–8 | F1–F8 (только редактор и dev-билд) | — |

## Как устроено

Сцена почти пустая: камера и объект `Game` с `GameManager`. Всё остальное собирается кодом из одного конфига, поэтому сцена не конфликтует при слиянии.

| Где | Что |
|---|---|
| `Assets/_Game/Configs/GameConfig.asset` | Все настройки: корпуса, пушки, враги, правила, цвета. Меняются в инспекторе |
| `Assets/_Game/Data/rooms.txt` | Комнаты в виде текстовых карт. Легенда в начале файла |
| `Scripts/Combat/Ricochet.cs` | Расчёт траектории с отскоками. Один код для линии прицела, рельсы и ИИ снайпера |
| `Scripts/Combat/ProjectileSystem.cs` | Кинематические снаряды: SphereCast на шаг + `Vector3.Reflect`. Пул снарядов |
| `Scripts/Echo/` | Эхо-волна: лучи до стен, кольцо на полу, отложенная подсветка стен |
| `Scripts/Tanks/` | Танк = корпус + пушка. Мозг: `PlayerController` или `EnemyBrain` (враг слышит шум) |
| `Scripts/Feel/` | Камера (тряска), частицы и вспышки света, синтезированные звуки |
| `Scripts/Core/GameEvents.cs` | Шина событий: геймплей сообщает, а звук, эффекты, UI и ИИ подписываются |
| `Scripts/UI/` | Интерфейс на uGUI, собирается кодом |
| `Editor/ProjectBuilder.cs` | Меню «Пуля — дура»: пересобрать сцену, собрать Windows-билд |

Почему снаряд не на физике: `PhysicMaterial.bounciness` теряет энергию на касательных ударах, а нам нужен предсказуемый рикошет, совпадающий с линией прицела.

### Как заменить графику и звук

- **Звук.** Компонент `Sfx` на объекте `Game` → список `Overrides`: выберите `SfxId` и перетащите клип. Без замены звук синтезируется кодом.
- **Модели.** `TankVisual.cs` собирает танк из примитивов. Заменяйте детали, сохранив объекты `Turret` и `Muzzle`.
- **Цвета и баланс.** `GameConfig.asset`.

## QA-прогон

`Пуля — дура → Собрать билд Windows`, затем:

```
Builds/Win/PulyaDura.exe -autotest -shots C:\temp\shots
```

Билд сам играет через Input System, как живой игрок: жмёт WASD, Shift, мышь, Пробел, Esc, R, Enter, G. Он проверяет 32 пункта: движение, тихий ход, прицел, выстрел, три скилла, паузу, рестарт, реакцию ИИ, снайпера через отскок, прохождение всех 8 комнат, победу и поражение, все 12 сочетаний корпус × пушка, нагрузку и время загрузки комнат. Результат (PASS/FAIL) пишется в `qa.txt`, а рядом кладутся скриншоты, в том числе при 4:3 и 21:9.

## Работа в команде

- Сцену `Main` правит только один человек. Комнаты и баланс правятся в `rooms.txt` и `GameConfig.asset`.
- Перед коммитом проверьте, что игра запускается с Play.
- Слияние сцен: настройте UnityYAMLMerge как mergetool (путь `Editor/Data/Tools/UnityYAMLMerge.exe`).
