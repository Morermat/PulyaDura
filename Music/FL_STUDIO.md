# Музыка и звуки в FL Studio вместе с Claude

Цель: своя музыка и свои звуки, без чужих семплов и мелодий. Тогда никаких проблем с авторскими правами на защите.

## Что есть в этой папке

| Файл | Что это |
|---|---|
| `make_midi.py` | Генератор набросков (Python, без зависимостей): `python make_midi.py` |
| `midi/calm_pad.mid` | Спокойный слой: пэд Dm–B♭–F–C, по 2 такта на аккорд |
| `midi/calm_arp.mid` | Редкие «колокольчики» поверх пэда |
| `midi/combat_bass.mid` | Боевой бас восьмыми |
| `midi/combat_drums.mid` | Ударные (GM-раскладка: подходят к FPC) |
| `midi/combat_lead.mid` | Мотив «рикошет» |
| `midi/full_sketch.mid` | Всё вместе, 5 дорожек |
| `midi/stinger_clear.mid`, `midi/stinger_death.mid` | Короткие джинглы: «комната чиста» и смерть |
| `midi/bounce_scale.mid` | 9 нот отскоков (как в игре), чтобы записать свой ксилофон |

Все наброски: **100 BPM, ре минор, 8 тактов**. Это темп и гармония игры, поэтому петли совпадут с битом: на него завязаны распев голоса и пульс интерфейса.

## Как подключить Claude к FL Studio

### Способ А: MIDI-файлы (надёжно, рекомендуем)

У FL Studio нет официального подключения к Claude. Самый простой путь: Claude пишет `.mid`, вы перетаскиваете его в FL.

1. Попросите Claude в этой папке, например: *«сделай вариант calm_arp помрачнее и реже»* или *«добавь в make_midi.py слой с хором на 16 тактов»*.
2. Claude меняет `make_midi.py` и запускает его. В `midi/` появятся новые файлы.
3. В FL Studio перетащите `.mid` из проводника в **Channel Rack** (FL спросит, куда импортировать) или откройте через **File → Import → MIDI file**.
4. На каждую дорожку поставьте свой инструмент. Ноты — это только партитура, звук делаете вы сами.

### Способ Б: MCP-сервер для FL Studio (экспериментально)

Есть любительские MCP-серверы (например, проект `flstudio-mcp` на GitHub). Они передают ноты в FL Studio в реальном времени через виртуальный MIDI-порт **loopMIDI** и MIDI-скрипт FL. Мы их **не проверяли**: настройка занимает около часа, а ломаются они при обновлениях FL. На джеме надёжнее способ А.

Если всё же хочется попробовать:

1. Установите loopMIDI и создайте порт.
2. Положите скрипт из репозитория сервера в `Documents/Image-Line/FL Studio/Settings/Hardware/<имя>/device_<имя>.py`.
3. В FL откройте **Options → MIDI settings** и выберите этот порт и скрипт.
4. В Claude Code подключите сервер командой `claude mcp add ...`, как написано в README проекта.

Перед установкой прочитайте код сервера: он выполняется на вашем компьютере.

## Как не нарушить авторские права

* **Мелодии и гармонии — свои.** Наброски из `make_midi.py` написаны с нуля. Не переносите на слух куски из Just Shapes & Beats, SUPERHOT и других игр. Брать можно только *настроение*: темп, жанр, плотность, приём «слово в бит».
* **Инструменты и семплы — штатные.** Встроенные синтезаторы и семплы FL Studio (FLEX, Sytrus, 3x Osc, FPC, Transistor Bass, бесплатные паки Image-Line) разрешено использовать в своей музыке. Лупы из интернета берите только с лицензией **CC0** (например, раздел CC0 на freesound.org). Записывайте источник каждого файла в `CREDITS.md`.
* **Голос — свой.** Запишите «ПУЛЯ», «ДУРА» и другие слова своим голосом в микрофон. Заглушки из Windows TTS лучше заменить до сдачи.
* **Не используйте** рипы игр, треки с YouTube, «бесплатные» паки без лицензии и ИИ-генераторы, условия которых запрещают коммерческое или публичное использование.

## Рецепт под игру

**Спокойный слой (calm):**

* пэд — FLEX или Sytrus, длинная атака (~0.8 с), Fruity Reeverb 2 на 40%;
* колокольчики — FM-звук, Fruity Delay 3 на 1/8 с пинг-понгом;
* по громкости тихо: это фон, по нему игрок слышит рикошеты.

**Боевой слой (combat):**

* те же 8 тактов + бас + FPC + мотив;
* в игре два слоя играют одновременно и плавно смешиваются, поэтому **длина и темп должны совпадать до сэмпла**.

**Экспорт:**

* **File → Export → WAV**, 44.1 kHz, 16 bit;
* *Tail*: **Wrap remainder** (хвост реверба переносится в начало, петля без щелчка);
* длина ровно 8 тактов: 19.2 с при 100 BPM.

**Звуки:**

* из `bounce_scale.mid` экспортируйте каждую ноту отдельным файлом, около 0.4 с, ксилофон или маримба. Сейчас игра просто повышает высоту одного «тинька»; свои ноты звучат живее;
* взрыв бочки, сирена ловушки, телепорт: синтезатор + шум, 0.3–1 с.

## Как вставить в игру

1. Положите WAV в `Assets/_Game/Audio/` (папку создайте).
2. На объекте **Game** в сцене `Main`:
   * компонент **MusicDirector**: поля *Calm Loop* и *Combat Loop* — ваши петли; темп оставьте 100, если писали в 100 BPM;
   * компонент **Announcer**: в списке *Variants* перетащите свои записи голоса в поля *First* и *Second*.
3. Импорт музыки: **Load Type → Streaming**. Импорт коротких звуков: **Decompress On Load**.
